{# FRAMMENTI RIUTILIZZABILI (macro Jinja). Una macro e' una funzione che produce HTML. Serve per gli elementi che compaiono in piu' pagine: se l'etichetta di stato appare in cinque template e la scrivi cinque volte, cambiarla significa cambiarla cinque volte, e dimenticarne una. COME SI USA, da un altro template: {% from "_frammenti.html" import stato_pratica %} {{ stato_pratica(pratica.stato) }} DA DOVE ARRIVANO StatoPratica, EsitoDocumento e simili Sono registrate come variabili globali di Jinja in create_app(): app.jinja_env.globals.update(StatoPratica=StatoPratica, ...) Per questo si possono usare in qualunque template senza passarle a render_template() ogni volta. ATTENZIONE alle macro: NON vedono le variabili globali del template che le chiama, ma quelle registrate in jinja_env.globals si', perche' sono dell'ambiente e non del singolo template. #} {# -------------------------------------------------------------------------- ETICHETTA DI STATO DELLA PRATICA. Il colore e il testo leggibile arrivano dai dizionari in app/enums.py: cosi' sono definiti una volta sola e valgono ovunque, template compresi. -------------------------------------------------------------------------- #} {% macro stato_pratica(stato) %} {{ StatoPratica.ETICHETTE.get(stato, stato) }} {% endmacro %} {# -------------------------------------------------------------------------- ESITO DI UN LEARNING AGREEMENT: in attesa / approvato / rifiutato. -------------------------------------------------------------------------- #} {% macro esito_documento(esito) %} {{ EsitoDocumento.ETICHETTE.get(esito, esito) }} {% endmacro %} {# -------------------------------------------------------------------------- ESITO DEL RICONOSCIMENTO DI UN ESAME. -------------------------------------------------------------------------- #} {% macro esito_riconoscimento(esito) %} {{ EsitoRiconoscimento.ETICHETTE.get(esito, esito) }} {% endmacro %} {# -------------------------------------------------------------------------- PERIODO DELLA MOBILITA', in forma leggibile. -------------------------------------------------------------------------- #} {% macro periodo(valore) %} {{ Periodo.ETICHETTE.get(valore, valore) }} {% endmacro %} {# -------------------------------------------------------------------------- DATA in formato italiano, oppure un trattino se non c'e'. Serve piu' spesso di quanto sembri: meta' delle date dello schema sono nullabili, e senza questo controllo il template stamperebbe "None". -------------------------------------------------------------------------- #} {% macro data(valore) %} {% if valore %}{{ valore.strftime('%d/%m/%Y') }}{% else %}—{% endif %} {% endmacro %} {# -------------------------------------------------------------------------- CAMPO DI UN FORM con etichetta ed eventuale messaggio d'errore. Per ora i due form esistenti (login) sono scritti a mano, ed e' giusto cosi': creare un'astrazione per un elemento usato una volta sola e' tempo perso. -------------------------------------------------------------------------- #} {% macro campo(nome, etichetta, valore='', tipo='text', errore=None, obbligatorio=True, aiuto=None) %}

{% endif %}
{% endmacro %}
